\# Basic Network Sniffer



A Python-based network packet sniffer built using Scapy for an internship project.



\## Features

\- Captures live network packets (TCP, UDP, ICMP, ARP)

\- Parses and displays source/destination IP, ports, protocol, and payload

\- Logs all captured packets to a CSV file

\- Saves raw captures to a .pcap file for Wireshark analysis



\## Requirements

\- Python 3.x

\- Scapy (`pip install scapy`)

\- Npcap (Windows only) - https://npcap.com
